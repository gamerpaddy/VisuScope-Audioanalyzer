First release of VisuScope, a real-time audio analyzer for Windows.

**What it does**
- Captures from a microphone, line input or the loopback of any playback device
- Spectrum, spectrogram / waterfall, 3D spectrum, stereo field (goniometer) and oscilloscope
- Distortion measurements (THD, THD+N, SNR, SINAD, SFDR, ENOB), octave analyzer, peak list and tuner
- Frequency response by sweep, impulse response with RT60, loudness (EBU R128), signal statistics
- A signal generator (tones, noise, IMD signals), a recorder and a file player
- A CSV logger with alarms, reference curves and limit masks

Unzip and run `visuscope.exe`. Windows only.
