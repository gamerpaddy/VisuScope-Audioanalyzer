Multichannel input, a multitrack timeline, a window manager and many more measurement tools.

**New since 1.0**
- Multi-channel input: pick any device channel as left and right, with a level meter per channel
- Live input monitor on a selectable output device
- Transfer function (magnitude, phase, coherence while music plays), sound level meter, stored traces, room acoustics, distortion sweeps, test sequences, measurement reports and EQ design
- **Timeline** (multitrack recorder and editor): record several tracks, load audio files, non-destructive editing, mixdown and stems, stereo tracks as left / right sub-tracks, undo and redo
- Desktop-style window manager: snapping, docking, 24 layout presets, saved layouts, undo / redo of layout changes
- Options dialog, version shown in the title bar, file dialogs remember their folder

**Fixes**
- Importing audio no longer blocks the interface
- Playing the timeline no longer replaces the live input in the analysers unless you ask for it
