Inputs you can bind to any control, signals that control any value, a draw track, and fixes for clicks and delay.

**Controls and inputs**
- Right-click a button or a slider's value box to bind it to a key, a MIDI note or controller, or a joystick button or axis (sliders get a range, buttons a toggle or momentary mode). All buttons in the program can be bound, including the timeline transport; media keys (play / pause, previous, next, stop) work, play / pause and previous start with defaults
- Every value of a node has a control input (a small dot): drag a wire from the output of any node onto it, so a generator, a timeline track or a drawing controls that value. Right-click the dot for the range. A new Control low-pass node smooths such a signal
- Right-click on a slider track resets it, clicking the value box types a number, holding the right mouse button pans the timeline, double-click removes a cursor, Shift+click snaps a cursor to a peak
- Routing graph on by default, with a Presets menu (analyse, monitor, equaliser, noise reduction, measure, record); the old input / output pickers are gone
- Draw track in the timeline: draw a curve with the mouse; it is not in the master mix, a Timeline out node can take it as a control signal
- The probe has its own output device; the status bar shows the total delay from input to output; Listen A-B also in the spectrogram; the stereo window can hide its parts; the version shows its build time

**Sound**
- Changing the gain of an output, a gain node, an input trim or a mixer input (or muting) no longer clicks: changes are eased over the block
- Muting an output keeps the stream running, so the sound output no longer takes it for a gap and grows its reserve
- A queue of a source with another sample rate than the graph was measured in the wrong unit: a timeline at 48 kHz in a 192 kHz graph could pile up more than a second before it was trimmed. Backlogs now count in time and are trimmed sooner
- A backlog that stays in the sound output is skipped with a short crossfade instead of being played away over minutes; the output no longer plays silence when the engine holds its queue for a moment
- The audio threads ask Windows for audio scheduling (the timeline playback too); the profiler shows the sound output queue and how often a backlog was skipped
