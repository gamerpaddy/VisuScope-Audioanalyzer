Changing a setting in the routing graph no longer makes the sound drop out.

- Every change of a setting (a gain, a mute, a slider that is dragged: up to 60 changes a second) rebuilt the running graph and set its clock back to zero. A graph without an input device runs on that clock (a timeline into a mixer into an output, for instance), so each change threw away the time since the last block: a few milliseconds of sound per change, heard as clicks and drops. The clock now goes on
