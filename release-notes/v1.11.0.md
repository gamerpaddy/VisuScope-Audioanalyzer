Measurements, traces and long files.

**Frequency response and distortion**
- The curve (and the phase, delay and coherence under it) is cut at the start and end frequency of the sweep; a *dBFS* switch shows the level instead of the gain (a -12 dBFS loopback reads -12); the phase line is kept within a turn of zero
- The sweep is taken from the analyser as it arrives, so its length is no longer limited by the size of the sample buffer (the limit is the memory of the analysis: about 40 s at 192 kHz); an optional *Full* range goes from 5 Hz to the top of the sample rate
- Swept harmonic distortion read far too high at low frequencies in a perfect loopback (-11 dB at 20 Hz, -48 dB at 30 Hz): the gates are Hann windows now (-68 dB at 30 Hz, -89 dB at 41 Hz for a 3 s sweep) and the points at the very start are left out. Curves of the swept analysis can be hidden one by one; the scale of the distortion plot is dB or percent (click the unit); the read-out is a box of one line per curve
- Sweeps work with the routing graph: a generator node that leads to an output or the analyser is enough
- The spectrum has *Noise density (per Hz)*: a noise reads the same at every FFT size. Switching between a log and a linear axis keeps the average, maximum and minimum

**Traces**
- New Traces window (Tools > Analyse): all stored curves overlaid, with show / hide, colour, name, reference, average, save and load. Saved traces were loaded black; fixed. Deleting, storing, averaging and loading can be undone with Ctrl+Z

**Sound**
- An output on a device of a lower sample rate than the graph filters what the device cannot play first (49 kHz at 192 kHz on a 48 kHz device was heard as 1 kHz)
- The size limit of an imported file follows the free memory (never below 300 million samples), so an hour of stereo at 48 kHz can be imported when there is room

Also in the 1.10 releases: bind any control to keys, MIDI, controllers; control inputs on every value and the Control low-pass node; the draw track; the routing graph on by default with presets; no clicks when changing gains; a changed setting no longer resets the engine clock.
