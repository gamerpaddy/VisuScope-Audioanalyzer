Null test, convolution, noise reduction, markers, automation and snapshots.

**New tool: Null test**
- Two signals (input channels or files) are lined up automatically (delay to a fraction of a sample, polarity, level) and subtracted; the residual is shown on a scope and a spectrum and the null depth is read out in dB
- Play signal A, B or the difference (with a boost for small errors)

**Routing graph**
- New nodes: phase shift / invert, convolution (any audio file as an impulse response), noise reduction (follows or learns the noise)
- Distortion and harmonics are one node now (the harmonic series is a distortion type); old files still load
- A / B buttons switch between two versions of a patch
- *Send to routing* in the EQ design window puts the fitted filters into an equalizer node

**Timeline**
- Polarity switch per track, markers and regions on the ruler, volume automation per track

**Analysis**
- Spectrogram difference mode (left minus right), *Listen A-B* to hear only the band between two cursors
- Session snapshots: the whole setup with notes, saved and restored by name

**Latency and performance**
- The output cushion adapts instead of being fixed at 60 ms; no memory allocation in the audio capture callback or per output block; timeline mixing reuses its buffers
