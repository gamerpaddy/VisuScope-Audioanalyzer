Window resizing, timeline track fixes and a spectrum reset button.

**Fixes**
- Resizing the application window (small to big, or any other way) no longer wrecks the window arrangement: the layout is remembered together with the size it was made for and every size is derived from that, so windows that were squeezed on the way down come back to their proportions on the way up. A tile is no longer needed afterwards
- Merging tracks keeps the look of the track it replaces: the channel rows with the mono and split left / right buttons stay available
- Tracks no longer have a volume fader per channel: use the balance for level differences. A gain set there by an older version is shown with a button to clear it

**New**
- *Reset max/min* button in the spectrum window, so the average, maximum and minimum traces can be restarted without opening the settings
