Input mappings: keys, MIDI and game controllers for buttons and sliders.

**Input mappings** (Options > Keys, MIDI and controllers)
- Bind keys (with Ctrl / Shift / Alt), MIDI notes and controllers, and the buttons and axes of game controllers and joysticks
- Actions: freeze, reset max/min, screenshot, monitor and generator on / off, tile, layouts 1 to 9, show / hide each window, the assistant, timeline play / record / loop / marker / split / undo / redo, routing probe / A-B / undo / redo
- Sliders: monitor volume, generator level and frequency, timeline master volume; each has its own range and can be reversed
- Press *Learn*, then press the key or move the control; the editor shows the connected MIDI inputs and controllers and the last input it saw
- The bindings are kept in `mappings.txt` in the settings folder. MIDI uses the Windows multimedia API, controllers and joysticks the system's game controller interfaces (XInput and DirectInput devices); other raw HID devices are not read
