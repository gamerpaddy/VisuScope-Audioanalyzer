The assistant walks you through a setup and can set up node patches.

**Assistant**
- **Walk me through**: instead of applying a plan at once, the assistant asks step by step: the input and its channels, the output, a microphone calibration file (or skip), and the parameters (sweep range, length, level, averages, generator tone, distortion mode). A summary comes last, and only then is everything set up, in this order: devices, calibration, parameters, routing patch, and finally the windows and their layout
- **Node presets**: each task suggests a routing patch (measure: generator to the output and input to the analysers; monitor; analyse; record onto a new timeline track). In the walk-through you can have it put the patch into the node editor; it switches the routing graph on and replaces the current patch, and Ctrl+Z in the node editor brings the old one back
- The quick buttons (Set up and start, Set up only) still work as before

**Timeline**
- The analysis panel no longer cuts its text off or loses the spectrum and spectrogram when it is small: the three parts keep a readable size and the stack scrolls, the statistics use two columns when there is room, and they use the height they have
