Fixes for the routing graph: node contents stay inside the node, and wires land on the port you aim at.

- Nodes: combo boxes cut their text to the node width, sliders leave room for their value box, and the longest choice labels (frequency shifter quality, distortion type) are shorter; no node kind reaches past its edge at any zoom (checked for all node kinds at 3 zoom levels)
- Mixer and other nodes with several ports: dropping a wire next to a port now picks the nearest port instead of the first one in reach, which could replace the wire of a connected input
